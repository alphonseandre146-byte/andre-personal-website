# JavaScript Features – Personal Website

## Introduction
This project involves adding five JavaScript features to my personal website to make it more interactive and user-friendly. JavaScript was used to add functionality and improve the overall user experience.

## Five JavaScript Features

### 1. Dark and Light Mode Toggle
This feature allows visitors to switch between dark mode and light mode. When the button is clicked, JavaScript changes the website's theme to the selected mode.

### 2. Digital Clock
The digital clock displays the current time on the website. It automatically updates every second using JavaScript, allowing visitors to see the current time.

### 3. Time-Based Welcome Message
This feature displays a greeting based on the current time of day. Visitors see "Good Morning", "Good Afternoon", or "Good Evening" depending on when they visit the website.

### 4. Paragraph Background Colour Changer
This feature allows visitors to change the background colour of a paragraph in the About section. Visitors can select different colours by clicking the available buttons.

### 5. Back-to-Top Button
The Back-to-Top button allows visitors to quickly return to the top of the website after scrolling down. The button appears when the visitor scrolls down the page.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- Visual Studio Code

## Conclusion
The five JavaScript features improve the functionality and interactivity of my personal website. They provide visitors with additional ways to interact with the website and create a better browsing experience and a more friendly user website.
